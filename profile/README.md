# Torad Labs

Independent ML research and open-source AI tooling by Marcos Damasceno (Austin, TX).

I build practical tools that help people work alongside AI honestly and effectively, and I run empirical experiments on how language models compute internally, how small models learn on consumer hardware, and where agent systems break under real use.
